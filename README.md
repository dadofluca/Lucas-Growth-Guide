# Luca's Growth Guide

Mobile-first baby feeding and routine tracker.

## First working build
- 8 oz is the primary/default feed button
- 5, 6, 7, and 8 oz quick logging
- Poop, cranky, happy, and sleep quick logs
- Daily ounces, feed count, and poop count
- Personalized estimated next-feed time based on recent feed intervals
- Today's timeline
- Local persistence and offline PWA support

This first build stores data on each device. Next: shared family sync/auth, full Insights + History screens, notifications, and AI pattern insights.
